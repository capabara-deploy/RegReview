## 1. Purpose

Phase-gate design review for the VP-400 firmware 4.2 configuration, covering design
inputs (DIR-0400 Rev H), design outputs (DOS-0400 Rev G), and the risk management
file (RMF-VP400).

## 2. Items Reviewed

- Design input requirements DIR-0400 Rev H.
- Design output specification DOS-0400 Rev G.
- Risk management file RMF-VP400.
- Verification status.

## 3. Discussion

The design outputs were reviewed against the design inputs. The firmware 4.2
secondary pressure check was reviewed as the control for the occlusion-related
hazards. The traceability matrix TM-VP400 was reviewed for completeness.

The occlusion-alarm response-time input DI-114 was noted as carrying a TBD
response-time value pending firmware characterization.

## 4. Conclusions

The design is judged complete and the outputs are judged to satisfy the design
inputs. The design is approved to proceed to release.
