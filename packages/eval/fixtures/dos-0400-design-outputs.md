**Document No.:** DOS-0400
**Rev:** G

**Owner:** K. Sethi, Design Engineering

## 1. Purpose

This specification indexes the design outputs for the VP-400 and serves as the
Device Master Record index. Each design output traces to a design input in
DIR-0400 per the traceability matrix TM-VP400.

## 2. Software and Firmware Outputs

- **DO-011** — Application software v3.2.1 (satisfies DI-011, DI-012).
- **DO-101** — Occlusion-detection logic in the safety controller (satisfies
  DI-101, DI-102).
- **DO-114** — Safety-controller firmware v4.2, secondary pressure check
  (implements the occlusion-alarm response behavior).

## 3. Hardware Outputs

- **DO-201** — PCA-4400 pump-control board assembly drawing.
- **DO-202** — Pressure transducer specification (see change history: transducer
  substitution per DCO-2025-0077).
- **DO-203** — Administration-set cassette channel drawing (see change history:
  chamfer revision per DCO-2026-0031).

## 4. Labeling Outputs

- **DO-301** — Instructions for Use, IFU-VP400.
